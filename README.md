# TP CI/CD avec Jenkins et GitHub
# tp-jenkins
pour notre tp avec jenskins

## Objectif

Ce projet a pour objectif de découvrir le fonctionnement d'une chaîne d'intégration continue (CI/CD) en utilisant Jenkins et GitHub.

## Outils utilisés

- Jenkins
- Git
- GitHub
- Java (JDK)

## Fonctionnement

Le pipeline Jenkins réalise les étapes suivantes :

1. Récupération du projet depuis GitHub.
2. Simulation de la compilation (Build).
3. Simulation des tests.
4. Simulation du déploiement.

## Résultat

Le pipeline s'exécute avec succès et affiche les différentes étapes dans la console Jenkins.
